# High Seas Pixel Privateer — One-World Dedicated Server

Authoritative Godot 4.7.2 headless WebSocket multiplayer server (`wss://`) for **High Seas Pixel Privateer**.

- **Play Online (Web Client):** https://gandidast.github.io/high-seas-privateer/
- **WebSocket Server Endpoint (Render):** `wss://high-seas-privateer.onrender.com`
- **Hugging Face Docker Space Ready:** Push to a Hugging Face Docker Space (requires Hugging Face PRO for Docker Spaces) and connect with `?server=wss://<user>-<space>.hf.space`.
- **Source Repository:** https://github.com/gandidast/high-seas-privateer
